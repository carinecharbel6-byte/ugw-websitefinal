About the Project

INDE 513 Information Systems · American University of Beirut · Fall 2026 · Instructor: Dr. Maysaa Jaafar

Design of a Travel and Events Management Database for U Group Worldwide

UGW is a travel and events agency with branches in Beirut and Dubai. This website is connected to the project's SQLite database, which was designed through the full process of the course:

  1. Requirements analysis and business rules
  2. Conceptual design with ER diagrams
  3. Relational design and the relational schema
  4. Data dictionary
  5. Functional dependencies and normalization to 3NF
  6. SQLite implementation: tables, constraints, triggers, sample data and queries

The database is built from the submitted files ugw_schema.sql and ugw_data.sql. The SQL Reports page reads ugw_queries.sql and the Database Rules page reads ugw_tests.sql, so the website always shows the same code as the report.
